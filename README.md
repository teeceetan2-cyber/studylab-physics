# ⚡ StudyLab — Physics

Interactive physics simulations built with Streamlit.

**Topics:**
- Projectile Motion — simulate launch with configurable velocity, angle, height, gravity
- Kinematics — v-t and s-t graphs for constant acceleration
- Snell's Law — visualize refraction and total internal reflection
- Ohm's Law — V/I/R calculator with I-V characteristic graph
- Simple Pendulum — period calculator with animated pendulum

### Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Or deploy on **Streamlit Cloud**: connect this repo and set entry point to `app.py`.
